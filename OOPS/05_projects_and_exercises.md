# 05 - Projects and Exercises

## Mini Project Ideas

1. **Library Management System**
   - Classes: `Book`, `Member`, `Library`, `Loan`
   - Features: borrow/return, due dates, search

2. **Banking App (CLI)**
   - Classes: `Account`, `SavingsAccount`, `CurrentAccount`, `Transaction`
   - Features: deposit, withdraw, transfer, statements

3. **School Portal**
   - Classes: `Student`, `Teacher`, `Course`, `GradeBook`
   - Features: enrollment, marks, reports

## Practice Prompts

- Refactor procedural code into classes
- Replace deep inheritance with composition
- Add interfaces/abstract classes for pluggability
- Write unit tests for class behavior

## Interview Questions

1. Difference between abstraction and encapsulation?
2. When should you avoid inheritance?
3. Explain runtime polymorphism with example.
4. Why is dependency inversion useful?
5. Composition vs inheritance: trade-offs?

## Learning Routine (4 weeks)

- **Week 1**: Basics + Encapsulation
- **Week 2**: Inheritance + Polymorphism + Abstraction
- **Week 3**: SOLID + Refactoring exercises
- **Week 4**: Design patterns + Mini project

Track your progress by implementing every concept with at least one working code sample.
